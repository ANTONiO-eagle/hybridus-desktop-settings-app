# Hybridus Desktop Settings 0.2 — исходный код

Отдельное приложение для Flipper Zero **F7** с конкретной прошивкой **Hybridus UI 0.7 preserve LTO / API 88.27** от 18.11.2026. Независимый проект [ANTONiO-eagle](https://github.com/ANTONiO-eagle): модификация Desktop Settings, не связанная с командами Unleashed или Flipper Devices и не являющаяся их официальной сборкой. Здесь полный исходный код приложения 0.2, ресурсы, `application.fam`, слой совместимости SDK и материалы проверки. **Файлы FAP, DFU, UF2 и исходники прошивки VGM не публикуются.** Версия 0.2 собрана заново и не является переизданием FAP от 18 ноября. Исходный комплект распространяется по GNU GPL v3; см. [LICENSE](LICENSE) и [NOTICE](NOTICE.md).

## Изменения и поведение

- Штатные пункты Desktop Settings сохранены. Добавлены строки **Shell Color**, **VGM Red / Green / Blue**, **Invert / Sync / Bezel** и **VGM Save**.
- RGB задаётся в пределах 0–31 / 0–63 / 0–31. Ручное изменение любого канала отключает Sync; Sync можно включить заново. Переключатели Invert и Bezel независимы от RGB.
- VGM Save сохраняет через API Flipper и показывает результат этой операции. Сообщение `Saved on Flipper` не означает, что RP2040 подтвердил получение или запись. Обновление картинки, расчёт цвета из RGB-диодов и отправка настроек модулю — задачи прошивки Flipper, а не FAP. Операции приложения не обновляют прошивку и не требуют места под новый код во встроенной flash Flipper.
- Новый FAP рассчитан на `/ext/apps/assets/desktop_settings.fap`, но перед заменой рабочего файла сохраните его копию.

## Пересборка без устройства

Проверено на Linux x86‑64: Git, Flipper toolchain 39 (ARM GCC 12.3.1, Python 3.11 из toolchain). Скрипт клонирует [Unleashed `unlshd-095`](https://github.com/DarkFlippers/unleashed-firmware/releases/tag/unlshd-095) по точному коммиту `9c6327764c18fc8376b5941aa8bde79fe681fe8f`, проверяет закреплённые подмодули, накладывает `source/` и собирает **только** цель приложения. При обычном запуске `fbt` подготавливает инструментарий; если точный инструментарий уже в `PATH`, используйте `FBT_NOENV=1`. Дополнение `targets/f7/` предназначено только для сборки FAP, **не для сборки ядра или пакета обновления**.

```sh
sh ./build.sh ./build-work
# Со включённым ARM binutils из toolchain 39 в PATH:
sh ./normalize-fap.sh ./build-work/build/f7-firmware-DC/.extapps/desktop_settings.fap ./desktop_settings.fap
sh ./tests/run.sh
```

Из двух сборок в разных деревьях удалена только `.gnu_debuglink` (привязка к отдельному отладочному ELF); полученные FAP побайтно совпали. Контрольная сумма и размер именно нормализованного результата — в `evidence/RESULT.md`. Скрипты не подключаются к Flipper и ничего не публикуют. Для host-тестов нужен компилятор C с UBSan.

## Проверки и ограничения

- Строгий `APPCHK` и `SDKCHK` пройдены. `verify-host.py` вторым независимым способом сверяет все импорты по таблице экспортов **точного образа Hybridus**, а не по номеру API. Скрипту нужен локальный архив проверенного образа; идентификатор приведён в `evidence/RESULT.md`. Скрипт не исполняет прошивку.
- Зависимости — 5 функций Hybridus: `hybridus_vgm_settings_get/set/save` и `hybridus_color_get/set`. Ядро содержит также шестую функцию `hybridus_vgm_settings_init`; `get` вызывает её сам, отдельного импорта в новом FAP нет. ABI и поля RGB565/Invert/Sync/Bezel сверены статически с тем образом. Это не оригинальный SDK от 18 ноября.
- **Не для стокового Unleashed 095 (API 88.26)** и не для произвольной прошивки с надписью API 88.27: они не обязаны экспортировать эти функции.

**Проверка на устройстве (отчёт владельца, 20.11.2026):** все функции приложения работали, включая синхронизацию во всех опробованных режимах и приложениях. Настройки сохранялись после перезагрузки Flipper и после отключения и повторного подключения VGM; зависаний не наблюдалось. Это результат проверки конкретной связки, а не гарантия для других прошивок.
